GESTOR COMERCIAL PANAMBY — V36
DASHBOARD OFICIAL + PIPELINE OPERACIONAL SEPARADOS

DASHBOARD
Somente informações vindas das planilhas/importações.
Movimentações, negociações e vendas feitas manualmente no Pipeline não alteram o Dashboard.

PIPELINE
Indicadores próprios:
- Contato
- Follow-up
- Negociação
- Venda concluída
- Total negociado
- Ticket médio negociado
- Líder em negociação
- Líder de vendas do Pipeline
- Total vendido no Pipeline
- Conversão do Pipeline

A venda do Pipeline usa o valor negociado salvo no próprio Pipeline.
O ranking do Pipeline não usa a base oficial de vendas importadas.

FOLLOW-UP / ALARMES
Continua independente para atividades, retornos e alertas.

APURAÇÃO DE METAS
Continua baseada na importação própria.

BANCO
Mantido o mesmo IndexedDB para preservar os dados existentes.
